# 05: Search Filters & Controls

**What to build:** Let users refine search results with filters for file type, chunk type, and result count — giving them control over what they see without overwhelming the interface.

**Blocked by:** #01 (needs styling foundation for filter UI)

**Status:** resolved

- [x] Filter by file type: checkboxes for Python, Markdown, JS, TS
- [x] Filter by chunk type: function, class, method, markdown, docstring
- [x] Top-k slider (3-20 results)
- [x] Filters in sidebar with clear visual hierarchy
- [x] Filter state persists across queries within a session
- [x] Results update when filters change (client-side filtering)
- [x] Filters styled consistently with the design system
